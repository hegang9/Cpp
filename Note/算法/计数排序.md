## 计数排序 (Counting Sort)
计数排序是一种不基于比较的线性时间复杂度排序算法。它适用于元素取值范围已知的整数集合，且当元素的取值范围跨度（极值差）不太大时非常高效。

#### 核心思想
统计原数组中每个元素在集合中出现的次数，然后根据统计结果算出该元素的正确位置，将其放回原/新数组中。

#### 算法步骤（稳定实现版）
1. **找出极值**：遍历原数组，找出最大元素 `max` 和最小元素 `min`。
2. **创建计数数组**：创建一个大小为 `max - min + 1` 的计数数组 `count`，并初始化所有元素为0。它用来保存 `[min, max]` 区间的元素出现的频率。
3. **统计频次**：遍历原数组，以元素值与最小值的偏差（`x - min`）作为下标，增加计数数组对应位置的计数值，即 `count[x - min]++`。
4. **计算位置（前缀和求位置）**：将计数数组变为前缀和数组，即 `count[i] += count[i - 1]`。此时 `count[i]` 表示小于等于数值 `i + min` 的元素个数。这一步主要为了保证相同元素的相对顺序不发生改变（稳定性）。
5. **反向填充**：为了维持稳定性，需要逆序遍历原数组。对于元素 `x`，它在排序后的数组中的位置下标为 `count[x - min] - 1`。放入目标位置后，将计数 `count[x - min]` 减1。

#### 复杂度分析
* **时间复杂度**：$O(n + k)$。$n$ 是数组长度，$k$ 是极值差 `max - min + 1`。遍历了原数组几遍，遍历了一次计数数组。
* **空间复杂度**：$O(n + k)$。需要一个额外的输出数组作为中间存储（大小为 $n$）和一个计数数组（大小为 $k$）。
* **稳定性**：稳定。由反序填充原数组机制保证，相同大小的元素依然保持其输入时的顺序。

#### C++ 代码实现
```cpp
#include <iostream>
#include <vector>
#include <algorithm>

void countingSort(std::vector<int>& arr) {
    if (arr.empty()) return;

    // 1. 寻找最小和最大元素
    int min_val = *std::min_element(arr.begin(), arr.end());
    int max_val = *std::max_element(arr.begin(), arr.end());

    int range = max_val - min_val + 1;
    // 2. 建立计数数组并初始化为0
    std::vector<int> count_arr(range, 0);

    // 3. 统计元素频率
    for (int num : arr) {
        count_arr[num - min_val]++;
    }

    // 4. 计算前缀和，用来定位到正确索引从而保证稳定性
    for (int i = 1; i < range; i++) {
        count_arr[i] += count_arr[i - 1];
    }

    // 5. 逆序构建输出数组，保持稳定性
    std::vector<int> output(arr.size());
    for (int i = arr.size() - 1; i >= 0; i--) {
        int target_pos = count_arr[arr[i] - min_val] - 1;
        output[target_pos] = arr[i];
        count_arr[arr[i] - min_val]--; // 放置完毕后该值剩余次数减1
    }

    // 6. 覆盖原临时数组
    arr = std::move(output);
}
```
