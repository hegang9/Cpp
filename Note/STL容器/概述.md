# STL 容器概述

## 顺序（序列）容器
vector、list、deque、array、forward_list 等

| 容器 | 特点 | 底层数据结构 |
| --- | --- | --- |
| vector | 动态数组，随机访问快，尾部插入快 | 动态数组 |
| list | 双向链表，任意位置插入/删除快 | 双向链表 |
| deque | 双端队列，头尾都能快速插入/删除 | 分段连续数组，指针数组 |
| array | 固定大小数组（C++11） | 固定大小数组 |
| forward_list | 单向链表（C++11），比 list 省空间 | 单向链表 |

## 关联容器（有序，红黑树）
set、map、multiset、multimap 等基于“红黑树”的有序存储

| 容器 | 特点 |
| --- | --- |
| set | 唯一元素自动排序 |
| multiset | 元素允许重复 |
| map | 键值对，键唯一，按键排序 |
| multimap | 键值对，键可重复，按键排序 |

## 无序关联容器（哈希表）
unordered_map、unordered_set、unordered_multimap、unordered_multiset 等基于“哈希表”的无序存储

| 容器 | 特点 |
| --- | --- |
| unordered_set | 无序唯一集合 |
| unordered_map | 无序键值对 |
| unordered_multiset | 无序可重复集合 |
| unordered_multimap | 无序可重复键值对 |

## 容器适配器
stack、queue、priority_queue 等

| 容器 | 特点 | 底层数据结构 |
| --- | --- | --- |
| stack | 后进先出 | 默认基于 deque |
| queue | 先进先出 | 默认基于 deque |
| priority_queue | 优先级高的元素先出 | 默认基于 vector |

> 注：STL 还包括配套的迭代器、算法、仿函数、适配器等组件，红黑树和哈希表的相关知识在 DataStruct 中。

## STL 的六大组件
STL（Standard Template Library，标准模板库）不仅局限于容器，它从广义上被称为“六大组件”，各组件之间相互协作，支撑起了 C++ 强大的泛型编程体系。除了前面重点列出的**容器 (Containers)** 外，其他五大核心组件如下：

### 1. 迭代器 (Iterators)
- **作用**：作为容器与算法之间的**解耦桥梁**。它提供了一种统一的接口及抽象机制，使算法能够透明地遍历和操作容器内的元素，而无需知晓或依赖该容器的底层内存布局和数据结构。
- **本质**：泛化的指针（Smart Pointers）。由于不同的容器底层数据结构各异（数组、链表、树），迭代器在内部重载了 `operator*`、`operator->`、`operator++` 等指针常用操作，为所有算法提供了一致的遍历接口。
- **分类**：分为输入迭代器、输出迭代器、前向迭代器、双向迭代器（如 `list`, `set`）、随机访问迭代器（如 `vector`, `deque`）。

### 2. 算法 (Algorithms)
- **作用**：用来操作容器中数据的具体动作与步骤。
- **特点**：STL 提供了约 100 多个实现好的经典算法，比如排序、查找、复制、替换、数学计算等（主要在 `<algorithm>` 和 `<numeric>` 头文件中）。
- **设计理念**：大部分算法都被设计成独立于特定的容器，即**泛型算法**。算法通过接收迭代器作为参数，从而实现在各种截然不同的容器上执行相同的逻辑。

### 3. 仿函数 / 函数对象 (Functors / Function Objects)
- **作用**：作为算法的**策略（策略模式）**，为算法提供自定义的处理逻辑。
- **本质**：一种重载了函数调用运算符 `operator()` 的类或结构体的对象。因为它能像普通函数一样被调用，所以在 STL 算法的参数回调中被广泛使用。
- **优势**：相比普通函数指针，仿函数不仅可以内联编译提高效率，还能在类内部携带状态（成员变量）。
- **应用场景**：比如使用 `std::sort` 时的比较规则、查找时的匹配条件等。

### 4. 适配器 (Adapters)
- **作用**：用来**修饰或改变**其他组件（容器、迭代器或仿函数）接口的一种机制，使原本不兼容的接口变得兼容。
- **分类**：
  - **容器适配器**：封装修饰底层容器，提供受限的接口。比如 `stack` 封锁了 `deque` 的大部分接口，只允许先入后出。
  - **迭代器适配器**：改变迭代器的行为。比如 `reverse_iterator` 将对迭代器的 `++` 操作转化为向反方向移动；`insert_iterator` 将赋值操作转化为向容器插入数据。
  - **仿函数适配器**：修饰现有的仿函数逻辑。比如把一个接受两个参数的仿函数通过绑定（`std::bind`）其中一个参数，变成只接受一个参数的仿函数。

### 5. 空间配置器 (Allocators)
- **作用**：负责 STL 中**内存空间的配置与管理**。所有的容器在底层都有一个默认的空间配置器在默默工作。
- **隐藏在幕后**：我们平时使用 `std::vector<int>` 实际上全称是 `std::vector<int, std::allocator<int>>`。Allocators 把内存分配 (`allocate`) 和 对象构造 (`construct`)，以及对象的析构 (`destroy`) 和 内存释放 (`deallocate`) 这两个阶段分离开来。
- **优势**：很多 STL 实现（如经典的 SGI STL）为了避免小型对象频繁分配引起的内存碎片问题，并提升分配效率，内部实现了一套非常精巧的两级空间配置器（内存池机制）。
