## list
`std::list` 是 C++ STL 中的一个双向链表容器，它提供了在常数时间内在任意位置插入和删除元素的能力。与 `std::vector` 和 `std::deque` 不同，`std::list` 的元素在内存中不连续存储，而是通过指针链接在一起。
### 1. 基本特性
- **双向链表**：`std::list` 支持双向迭代器，可以从头部和尾部遍历链表。
- **内存分配**：每个元素都单独分配内存，因此在插入和删除元素时不会导致其他元素的移动。
- **不支持随机访问**：由于元素不连续存储，`std::list` 不支持随机访问，无法使用下标运算符 `[]` 来访问元素。
### 2. 常用成员函数
- **`push_back(const T& value)`**：在链表尾部插入一个元素。
- **`push_front(const T& value)`**：在链表头部插入一个元素。
- **`pop_back()`**：删除链表尾部的元素。
- **`pop_front()`**：删除链表头部的元素。
- **`insert(iterator pos, const T& value)`**：在指定位置插入一个元素。
- **`erase(iterator pos)`**：删除指定位置的元素。
- **`begin()`** / **`end()`**：返回指向链表第一个元素和最后一个元素之后位置的迭代器。
- **`size()`**：返回链表中元素的个数（C++11 起强制时间复杂度为 $O(1)$，内部维护了一个 count）。

### 3. 与 forward_list 的区别及 `size()` 函数说明

在 C++ STL 中，除了双向链表 `std::list`，C++11 还引入了单向链表 `std::forward_list`。关于获取大小的 `size()` 函数，它们有非常显著的区别：

*   **`std::list` 是提供 `size()` 函数的。**
    *   在 C++98/03 标准中，`list.size()` 的时间复杂度允许为 $O(N)$（因为有些早期的 STL 实现为了保证 `splice` 拼接操作是 $O(1)$，没有在内部维护元素个数计数器）。
    *   **从 C++11 标准开始**，委员会规定 `list.size()` 必须是 **$O(1)$ 的时间复杂度**。这意味着现代 C++ 编译器在 `list` 容器内部维护了一个 `size_t` 的计数器，任何插入和删除都会同步更新这个计数器。但代价是，在这之后具有两个迭代器参数的区间形 `splice` 操作变成了 $O(N)$，因为它需要遍历计算拼接了多少个元素来更新计数器。

*   **`std::forward_list` 绝对不提供 `size()` 函数。**
    *   `std::forward_list` 的设计初衷是**极度追求极致的轻量化和空间效率**，它的内部没有任何多余的数据成员，完全等价于手写的 C 语言单向链表（哪怕是多加一个用于记录大小的字节都不被允许）。
    *   如果它提供 `size()` 却不维护计数器，那么遍历链表需要 $O(N)$，这违反了常数时间法则；如果它内部增加一个计数成员，那就违背了它比 `std::list` 占用更小内存的初衷。因此，标准委员会刻意去掉了 `forward_list` 的 `size()` 方法。如果想要知道单链表的距离，只能用 `std::distance(flist.begin(), flist.end())`（此时时间复杂度为 $O(N)$）。
