## 泛型编程
泛型编程时一种编程范式，其核心思想是 **编写与类型无关的代码**，使同一份代码能够处理不同的数据类型，而不牺牲类型安全和性能。

### 泛型编程实现方法
1. 模板
2. C++20引入的 concept

### Concept
Concept 是 C++20 引入的特性,用于对模板参数进行 **编译期约束**,解决传统模板报错信息晦涩的问题。

#### 定义语法

**基本形式**：
```cpp
template <typename T>
concept 概念名 = 约束表达式;
```

**约束表达式**可以是：
- 编译期布尔值（`true`/`false`、`sizeof` 判断等）
- `requires` 表达式（检查类型是否支持某些操作）
- 标准库 concept（如 `std::integral<T>`）
- 逻辑组合（`&&`、`||`、`!`）

**示例**：
```cpp
#include <concepts>

// 定义：要求类型 T 可以相加
template <typename T>
concept Addable = requires(T a, T b) {
    { a + b } -> std::convertible_to<T>;
};

// 定义：要求类型 T 是数值类型
template <typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;
```

#### 四种使用方式

假设已定义 concept `Addable`，以下四种方式等价：

```cpp
// 1. requires 子句（前置约束）
template <typename T> requires Addable<T>
T add(T a, T b) {
    return a + b;
}

// 2. 直接替代 typename（最简洁）
template <Addable T>
T add(T a, T b) {
    return a + b;
}

// 3. 后置 requires（约束写在函数签名后）
template <typename T>
T add(T a, T b) requires Addable<T> {
    return a + b;
}

// 4. 简写形式（auto + concept）
auto add(Addable auto a, Addable auto b) {
    return a + b;
}
```

**使用场景对比**：
- 方式 2 最简洁，适合单一约束
- 方式 1/3 适合复杂约束或需要逻辑组合（`requires A<T> && B<T>`）
- 方式 4 适合简短的泛型函数

#### requires 表达式中的四种约束

`requires` 表达式用来检查类型是否满足一组操作/特性，语法：
```cpp
requires(参数列表) { 约束列表 }
```

**四种约束类型**：

```cpp
template <typename T>
concept Example = requires(T a, T b) {
    // 1. 简单要求：表达式必须合法（可编译），不关心返回值
    a + b;
    a.size();

    // 2. 类型要求：要求类型存在
    typename T::value_type;
    typename T::iterator;

    // 3. 复合要求：表达式合法 + 返回值满足约束
    { a * b } -> std::convertible_to<T>;
    { a == b } -> std::same_as<bool>;

    // 4. 嵌套要求：嵌入其他编译期布尔表达式
    requires std::is_default_constructible_v<T>;
    requires sizeof(T) <= 8;
};
```

**完整示例**：
```cpp
#include <concepts>
#include <iostream>

template <typename T>
concept Container = requires(T c) {
    typename T::value_type;              // 有 value_type
    { c.size() } -> std::convertible_to<size_t>; // 有 size() 方法
    { c.begin() } -> std::same_as<typename T::iterator>; // 有 begin()
};

template <Container C>
void print_size(const C& c) {
    std::cout << "Size: " << c.size() << std::endl;
}

int main() {
    std::vector<int> v = {1, 2, 3};
    print_size(v);  // OK: vector 满足 Container
    // print_size(42);  // 编译错误：int 不满足 Container
}
```

#### 常用标准库 Concepts（`<concepts>`）
- `std::integral` / `std::floating_point` — 整数/浮点类型
- `std::same_as<T, U>` — 同一类型
- `std::convertible_to<T, U>` — 可转换
- `std::copyable` / `std::movable` — 可拷贝/移动
- `std::equality_comparable` / `std::totally_ordered` — 可比较
