## 尾递归
当递归调用是函数的最后一个操作且在返回时直接返回递归调用的结果，编译器可以重用当前栈帧而非新增，避免因深度递归导致的栈溢出问题。这种优化称为尾递归优化（Tail Recursion Optimization）。尾递归函数可以被编译器转换为迭代形式，从而提高性能和减少内存使用。

## 代码示例
```cpp
#include <iostream>

int factorial(int n, int result = 1) {
    if (n == 0) return result;
    return factorial(n - 1, n * result);
}

int main() {
    int n = 5;
    std::cout << "Factorial of " << n << " is " << factorial(n) << std::endl;
    return 0;
}
```在这个示例中，`factorial` 函数是一个尾递归函数，因为它的最后一个操作是调用自身。编译器可以优化这个函数，使其在计算阶乘时不会增加新的栈帧，从而避免栈溢出问题。
