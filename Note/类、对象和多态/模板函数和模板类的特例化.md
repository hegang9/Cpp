# C++ 模板函数和模板类的特例化（特化）

在 C++ 中，模板（Template）提供了一种泛型编程的机制。但有时候，通用的模板实现可能不适合某些特定的数据类型，或者对于某些类型我们需要提供更高效或者完全不同的实现。这时候就需要用到**模板特例化（Template Specialization）**。

模板特例化分为两种：
1. **全特化（Full Specialization）**：为模板的所有参数提供具体的类型。
2. **偏特化（Partial Specialization）**：为模板的部分参数提供具体类型，或者对参数进一步限制（如指针、引用等）。

---

## 1. 模板类的特例化

类模板既支持**全特化**，也支持**偏特化**。

### 1.1 类模板全特化
将类模板的所有模板参数都指定为具体的类型。全特化版本的类模板是一个全新的类，它的成员函数和成员变量可以与通用模板完全不同。

```cpp
// 1. 通用模板
template <typename T1, typename T2>
class MyClass {
public:
    void print() {
        std::cout << "通用模板" << std::endl;
    }
};

// 2. 全特化（T1 为 int，T2 为 double）
template <>
class MyClass<int, double> {
public:
    void print() {
        std::cout << "全特化版本：<int, double>" << std::endl;
    }
};
```

### 1.2 类模板偏特化
偏特化是指只指定一部分模板参数，或者限制模板参数的类型（如限定为指针、引用、const 等），使得它比通用模板更加具体，但仍有一部分参数保留为泛型。

```cpp
// 1. 通用模板
template <typename T1, typename T2>
class MyClass {
public:
    void print() {
        std::cout << "通用模板" << std::endl;
    }
};

// 2. 偏特化（部分参数特化：T2 指定为 int）
template <typename T1>
class MyClass<T1, int> {
public:
    void print() {
        std::cout << "偏特化版本：<T1, int>" << std::endl;
    }
};

// 3. 偏特化（类型限制特化：要求参数是指针类型）
template <typename T1, typename T2>
class MyClass<T1*, T2*> {
public:
    void print() {
        std::cout << "偏特化版本：两个参数都是指针" << std::endl;
    }
};
```

## 2. 模板函数的特例化

**注意：函数模板只支持全特化，不支持偏特化。**
如果要实现类似函数模板偏特化的效果，通常是通过**函数重载（Function Overloading）**来实现的。

### 2.1 函数模板全特化

```cpp
// 1. 通用函数模板
template <typename T>
void printVal(T val) {
    std::cout << "通用模板：" << val << std::endl;
}

// 2. 全特化（针对 T 为 int）
template <>
void printVal<int>(int val) {
    std::cout << "全特化版本(int)：" << val << std::endl;
}
```

### 2.2 函数模板为什么不支持偏特化？ / 如何替代？
C++ 标准不允许对函数模板进行偏特化。因为函数本身是允许重载的，通过非模板函数或者另一个重载的模板函数，就可以达到和偏特化一样的效果。编译器在进行函数匹配时，重载解析的规则已经足够处理这种情况。

```cpp
// 1. 通用函数模板
template <typename T1, typename T2>
void func(T1 a, T2 b) {
    std::cout << "通用函数模板" << std::endl;
}

// 2. 重载函数模板（相当于对指针类型的 "偏特化"）
template <typename T1, typename T2>
void func(T1* a, T2* b) {
    std::cout << "重载函数模板（接受指针）" << std::endl;
}

// 3. 全特化
template <>
void func<int, int>(int a, int b) {
    std::cout << "全特化版本 <int, int>" << std::endl;
}
```

## 3. 匹配优先级与注意事项

当存在通用模板、特例化模板和普通函数时，编译器的匹配优先级规则如下：

1. **对于类模板**：全特化 > 偏特化 > 通用模板。编译器总是选择“最特殊（最具体）”的一个。
2. **对于函数及函数模板**：普通非模板函数 > 函数模板的特化版本 / 更加具体的重载模板函数 > 通用的函数模板。

### 注意事项：
1. **全特化必须在通用模板之后声明**：也就是在特化之前，编译器必须先看到主模板（Primary Template）的声明。
2. **函数模板尽量避免全特化，优先使用重载**：著名的 C++ 专家（如 Herb Sutter）建议，对于函数模板，尽量使用重载而不是全特化。因为在混合使用重载和全特化时，由于全特化版本不参与重载解析（它只是依附于某个主模板），可能会导致意料之外的匹配结果。
3. **类模板成员的全特化**：不仅可以对整个类模板进行特化，还可以只对类模板的某个成员函数进行全特化（但该成员函数所属的类模板参数在这种情况下也被确定）。

```cpp
template <typename T>
class Test {
public:
    void doSomething() {
        std::cout << "通用情况" << std::endl;
    }
};

// 仅全特化成员函数
template <>
void Test<int>::doSomething() {
    std::cout << "int 类型的特化版本" << std::endl;
}
```
