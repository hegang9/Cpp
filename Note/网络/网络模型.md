## Reactor 模型
Reactor 模型是一种事件驱动的并发模型，核心思想是通过事件通知机制来处理 I/O 事件，避免了传统线程模型中的阻塞和上下文切换开销。

在 Reactor 模型中，应用程序通过注册事件（如可读、可写、异常等）和对应的回调函数，当事件发生时，事件循环会调用相应的回调函数来处理事件。这种模型适用于高并发场景，能够有效利用系统资源，提高性能。

常见的 Reactor 模型实现包括 Linux 的 epoll、Windows 的 IOCP（也可用于 Proactor 模型）等。

## Proactor 模型
Proactor 模型也是一种事件驱动的并发模型，但与 Reactor 不同的是，Proactor 模型是基于完成事件通知机制的，即 I/O 操作完成后由操作系统通知应用程序，而不是应用程序主动等待事件发生。这种模型在某些平台（如 Windows 的 IOCP）上表现更好。io_uring 是 Linux 上的 Proactor 模型实现，提供了高效的异步 I/O 支持。

## 选择合适的模型
- **Reactor**：适用于大多数网络应用，尤其是跨平台开发，如使用 epoll、select、poll 等机制的应用。
- **Proactor**：适用于需要高性能异步 I/O 的应用，特别是在 Windows 平台上，或使用 io_uring 的 Linux 应用。
