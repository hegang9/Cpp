## 函数指针

### 定义

函数指针是指向函数的指针变量，可以通过它调用函数。

### 语法

```cpp
返回类型 (*指针名)(参数类型列表);
```

### 示例

```cpp
#include <iostream>

void printHello() {
    std::cout << "Hello, World!" << std::endl;
}

int main() {
    void (*funcPtr)() = printHello; // 定义函数指针并初始化
    funcPtr(); // 通过函数指针调用函数
    return 0;
}
```

### 使用场景：
- 回调函数：将函数指针作为参数传递给另一个函数，以实现回调机制。
- 动态函数调用：根据条件选择不同的函数进行调用。
- 实现多态：通过函数指针数组实现类似于虚函数的功能。
- 策略模式：通过函数指针实现不同算法的切换

#### 回调函数示例

```cpp
#include <iostream>

void onDone(int code) {
    std::cout << "done: " << code << std::endl;
}

void doWork(void (*callback)(int)) {
    int result = 42;
    callback(result);
}

int main() {
    doWork(onDone);
    return 0;
}
```

#### 动态函数调用示例

```cpp
#include <iostream>

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

int main() {
    bool useAdd = false;
    int (*op)(int, int) = useAdd ? add : sub;
    std::cout << op(10, 3) << std::endl;
    return 0;
}
```

#### 函数指针数组模拟多态示例

```cpp
#include <iostream>

void drawCircle() { std::cout << "circle" << std::endl; }
void drawSquare() { std::cout << "square" << std::endl; }
void drawTriangle() { std::cout << "triangle" << std::endl; }

int main() {
    void (*drawers[])() = { drawCircle, drawSquare, drawTriangle };
    for (auto draw : drawers) {
        draw();
    }
    return 0;
}
```

#### 策略模式示例

```cpp
#include <iostream>

int asc(int a, int b) { return a < b; }
int desc(int a, int b) { return a > b; }

void sort2(int &x, int &y, int (*cmp)(int, int)) {
    if (cmp(y, x)) {
        int temp = x;
        x = y;
        y = temp;
    }
}

int main() {
    int a = 7, b = 3;
    sort2(a, b, asc);
    std::cout << a << "," << b << std::endl;
    sort2(a, b, desc);
    std::cout << a << "," << b << std::endl;
    return 0;
}
```
